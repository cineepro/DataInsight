# Schéma des collections — miroir résumé

Voir le document complet "DataInsight-Architecture.md" pour le détail
attribut par attribut. Ce fichier sert de référence rapide pour les
variables d'environnement des Functions (les noms ci-dessous doivent
correspondre EXACTEMENT aux Collection IDs créés dans la console).

- `tenants` → env var `APPWRITE_COLLECTION_TENANTS`
- `scans_restaurant` → env var `APPWRITE_COLLECTION_SCANS_RESTAURANT`
- `scans_pharmacie` → env var `APPWRITE_COLLECTION_SCANS_PHARMACIE`
- `scans_entreprise` → env var `APPWRITE_COLLECTION_SCANS_ENTREPRISE`
- `operational_metrics` → env var `APPWRITE_COLLECTION_OPERATIONAL_METRICS`
- `weekly_reports` → env var `APPWRITE_COLLECTION_WEEKLY_REPORTS`

Database ID → env var `APPWRITE_DATABASE_ID`
